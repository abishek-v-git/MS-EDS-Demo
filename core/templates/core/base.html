Upload EDS Excel files
  • Several files are imported together or not at all: if one can't be read, nothing is saved. You see a preview before anything is saved.
  • Files are applied in filename order (prefix them 01_, 02_ …); where two files give a different value for the same demand line, the later file wins and the preview lists it.
  • Columns are matched by header name; order doesn't matter.
  • Rows are keyed on Demand-line ID. Existing demand lines are updated, new ones get a new EDS record.
  • EDS Record ID, Current gate, Record owner and backup, Created / Refreshed / Review dates, Rack configuration ID and Platform SKU/MDM ID are generated by the system; leave them out of the file.
  • Only the columns in your file are overwritten.
  • Monthly profile is one column per month (e.g. Nov 2026): just type the quantity. Blank month = none.
